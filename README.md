# Dendritic Config

My NixOS and Home-Manager configuration monorepo. Covers a Wayland-first desktop (Niri compositor) and laptop, a gaming-capable setup with Steam + GPU recording, and a Nushell + Neovim development environment — all declared in one place. It also runs a small homelab VPS (hoseki).

## What's Configured

| Area | Tools |
|------|-------|
| Shell & CLI | Nushell, Starship (eldritch theme), Zoxide, Carapace, Tmux, Eza, Direnv, Fastfetch |
| Editor | Neovim (nixvim) — LSP, Treesitter, Telescope, Blink completions; Micro |
| Desktop | Niri + Noctalia shell, which-key launcher menus, Stylix theming, Ghostty, linux-wallpaperengine, Plymouth splash |
| Gaming | Steam + Proton + SteamTinkerLaunch, Gamemode, GPU Screen Recorder, CloneHero, Prism Launcher |
| Apps | Zen Browser, Mattermost, Antra, Calibre, Proton apps, media tools (ani-cli, yt-dlp, twitch), Flatpak |
| Dev tooling | Claude Code, opencode, devenv, lazygit |
| Server | Traefik, Paperless, Filebrowser, fail2ban, agenix secrets, terranix-provisioned Linode |
| Custom packages | Small apps and themes in `packages/` |

## Directory Structure

```
dendritic-config/
├── flake.nix          # generated by flake-file — don't edit by hand
├── .justfile          # just command recipes
├── modules/
│   ├── nix/           # flake plumbing: inputs, overlays, formatter, hooks, agenix, package report
│   ├── lib/           # custom options & helpers: nixosHosts, homeConfigs, user helper, preferences
│   ├── system/        # core NixOS: base, boot, sound, fonts, stylix, vm
│   ├── features/      # one dir per feature, each holding its NixOS + Home-Manager parts
│   │   ├── shell/  editors/  desktop/  niri/  gaming/  dev/
│   │   └── media/  proton/  work/  printing/  virt/
│   ├── services/      # syncthing, wbtv; server/ holds homelab services (traefik, paperless, …)
│   ├── hosts/         # phos, wonderland, wsl, hoseki, mini — hardware + feature list
│   ├── users/         # dragon, cinnabar — account + Home-Manager entry
│   └── secrets/       # shared agenix secrets
├── packages/          # custom packages, available as pkgs.local.<name>
└── scripts/           # pkgs.nu (package listing)
```

## How It Works

This repo uses the [dendritic](https://github.com/mightyiam/dendritic) pattern with [import-tree](https://github.com/vic/import-tree): every `.nix` file under `modules/` is loaded automatically as its own flake-parts module. There are no import lists to maintain, and any path containing `/_` is skipped (handy for work in progress).

**Features, not file types.** Modules are grouped by what they do rather than by kind. A feature is a single file or directory that declares everything it needs — its NixOS side, its Home-Manager side, unfree allowances, flake inputs, and packages. For example, `media` adds a set of user apps, while `wallpaperengine` adds a user service plus the niri layer rule it needs.

**Hosts compose features.** A host file holds hardware, networking, keys, and a list of features to import. Facts that belong to one machine, like where its Steam library lives, are set on that host.

**System vs user.** Services, drivers, and anything needing system integration live in NixOS modules. User apps and CLI tools live in Home-Manager, pulled in by the feature that owns them.

**Niri.** The compositor config is split by concern — settings, keybinds, which-key menus, and the noctalia shell. Any feature can add its own entry to a launcher menu, so an app's keybind lives next to the app.

**Custom packages.** Packages in `packages/`, plus packages from flake inputs, are exposed as `pkgs.local.*` on every host and in standalone Home-Manager.

### Helper modules

- **`lib/nixos-hosts.nix`** - Defines the `nixosHosts` option. All the boilerplate of a nixosConfiguration.
- **`lib/home-configs.nix`** - Defines the `homeConfigs` option. Builds a standalone homeConfiguration for a user.
- **`lib/users.nix`** - The user helper: creates the account and wires the user's Home-Manager config.
- **`lib/preferences.nix`** - Shared preferences such as the user name and theme.

### Flake Outputs

The flake produces:
- `flake.nixosConfigurations` - All defined NixOS systems
- `flake.homeConfigurations` - All defined home-manager configs
- `flake.packages.*` - Custom packages, wrapped programs (niri, neovim, …), [flake-file](https://flake-file.oeiuwq.com/) tools (`write-flake`), and the terranix config for hoseki
- `flake.lib.*` - Helper functions, including `packageReportFor` (used by `just pkgs`)
- `flake.schemas.*` - Custom schema to allow checks and viewing of custom outputs

## Usage

[Just](https://just.systems) is used as the command runner for this project. Most commands use [nh](https://github.com/nix-community/nh) to simplify Nix operations and remove the need for sudo.

```bash
just switch        # fmt + check + build + activate (current host)
just switch phos   # same, targeting a specific host
just home          # switch home-manager config for current user
just test          # dry-run build to check for errors
just check         # format, regenerate flake.nix, run flake checks
just pkgs [host]   # list packages a host installs, grouped by feature (--all for everything)
just vm            # build and launch a VM for the current host
just up            # update flake inputs
just --list        # full command reference
```

In nushell, `use scripts/pkgs.nu` gives a `pkgs <host>` command that returns a table you can pipe.

## Adding a New Host

1. Create the host directory:
   ```bash
   mkdir -p modules/hosts/<name>
   ```

2. Create `modules/hosts/<name>/<name>.nix`:
   ```nix
   { self, ... }:
   {
     nixosHosts.<name>.enable = true;

     flake.modules.nixos."confs/<name>" = {
       imports = with self.modules.nixos; [
         base
         boot
         dragon
         desktop
         # add more features...
       ];

       system.stateVersion = "25.11";
     };
   }
   ```

## Adding a New User

1. Create the user directory:
   ```bash
   mkdir -p modules/users/<username>
   ```

2. Create `modules/users/<username>/<username>.nix`:
   ```nix
   {
     self,
     lib,
     ...
   }:
   {
     homeConfigs.<username>.enable = true;

     flake.modules = lib.mkMerge [
       (self.lib.user "<username>" true) # account + Home-Manager wiring
       {
         nixos.<username>.imports = with self.modules.nixos; [
           environment
           editors
         ];
       }
       {
         homeManager.<username> = {
           imports = with self.modules.homeManager; [
             stylix
             shell
           ];
           home.stateVersion = "25.11";
         };
       }
     ];
   }
   ```

## Adding a Feature

1. Create `modules/features/<feature>/<feature>.nix` defining `flake.modules.nixos.<feature>`, `flake.modules.homeManager.<feature>`, or both.
2. Add `<feature>` to the imports of any host that should have it.

## Testing in VM

```bash
just vm <host>

```
